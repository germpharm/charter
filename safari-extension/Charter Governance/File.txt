1. Project Vision & Business Context
We are building the world’s first true Agentic as a Service (AgaaS) platform for residential new-home construction (exactly as Jensen Huang described at GTC 2026).
Core promise to OLO Builders:
10× visibility + homeowner delight at ~1/10th the cost of traditional tools.
Foremen and office staff do almost zero extra work. Agents handle schedule optimization, homeowner updates, risk flagging, and actions — every single one governed by CharterAgent.ai for immutable audit trails and full explainability.
Commercial terms (for your awareness only):

OLO pays one-time pilot implementation (~$8k).
They receive perpetual, unlimited, self-hostable license + full source + admin keys for the entire franchise network.
Ongoing AgaaS fee (recurring income): $79 flat per active build/month OR $499 flat per franchise location/month (we centrally host/run the agent swarm).
We retain full IP of the Agentic Acceleration Engine + Charter layer.

TheTrades integration is optional (carrot only).

5. Phase 1 MVP – 6 Weeks (Ship & Wow Trent)
Goal: Live on Trent’s Salt Lake location with 3–5 concurrent builds.
Must-ship features:

Field PWA – GPS check-in/out, task complete, guided photo upload, voice blockers, full offline sync
Office Dashboard – portfolio grid, job detail, Gantt with critical path, timeline feed
Agentic Acceleration Engine baseline – DAG critical path, velocity tracking, delay propagation + cross-job impact, SMS alerts, Charter governance on every action
Homeowner Portal (fully agentic) – Homeowner names the home at signing → named agent (“Piney”) auto-generates guided photo prompts for foreman, analyzes photos, writes updates in OLO voice, sends personalized email/SMS, public read-only portal link
Full Inspection API integration (Accela + Cloudpermit for UT/ID/CO; fallback SMS form)
Plan template import → auto-generate DAG

Out of scope for Phase 1: budget tracking, weather, advanced materials, full optimizer, multi-tenancy.
6-Week Delivery Schedule:

Weeks 1-2: Supabase schema + auth + Field PWA skeleton
Week 3: Office dashboard + critical path DAG
Week 4: CharterAgent.ai integration + basic agent swarm
Week 5: Homeowner Agent + photo prompts + automated updates
Week 6: Inspection APIs + SMS alerts + real pilot data import + deployment
